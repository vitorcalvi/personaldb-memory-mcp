# PersonalDB Memory Support

For bugs, installation problems, authentication failures, or feature requests, open an issue at:

https://github.com/vitorcalvi/personaldb-memory-mcp/issues

When reporting a problem, include the failing tool name, HTTP status or error message, and whether the issue occurs during plugin installation, OAuth authorization, or MCP tool execution.

Do not post OAuth tokens, API keys, private memory text, embedding vectors, or other secrets in public issues.
